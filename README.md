## Install

Build Vencord from source, put this folder in `src/userplugins/actualFullScreen`, then run:

```sh
pnpm build
```

See https://docs.vencord.dev/installing/custom-plugins/ if you have not built Vencord before.

Enable ActualFullScreen under Settings, Plugins.
